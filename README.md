# روزنا — نظام إدارة الاستقدام

هذه نسخة أولية جاهزة للرفع إلى GitHub Pages.

المزايا:
- تسجيل دخول محلي على نفس الجهاز.
- ملفات العاملات: إضافة، تعديل، حذف، بحث وفلاتر.
- العقود.
- الدفعات.
- تقارير قابلة للطباعة والحفظ PDF من المتصفح.
- نسخة احتياطية واستيراد JSON.
- واجهة عربية ومتجاوبة مع الآيفون.

مهم:
هذه النسخة تخزن البيانات داخل المتصفح (localStorage)، لذلك ليست قاعدة بيانات سحابية ولا توفر دخولاً متعدد المستخدمين بشكل آمن.
إذا أردت نسخة نهائية للشركة فيها مستخدمون متعددون وصلاحيات وكلمة مرور حقيقية وقاعدة بيانات مشتركة، نحتاج ربطها بخدمة Backend مثل Supabase أو Firebase.

للتجربة:
1. افتح index.html.
2. في أول دخول أدخل البريد وكلمة المرور التي تريدها؛ سيتم حفظهما على هذا الجهاز.
3. بعد ذلك استخدم النظام.
