# روزنا — النسخة المطوّرة

هذه النسخة تعدّل المشروع الأصلي ولا تلغي وظائفه الأساسية.

## الإضافات
- تكلفة كل عاملة مفصلة في 15 بنداً: ختم نقابة، التأمين، طوابع، تصريح العمل، العقد، إرسالية العقود، التأشيرة، توصيل المطار، الفحص الطبي، مصاريف جانبية للفحص الطبي، صور شخصية، الإقامة، العمولة، الضريبة، مصاريف جانبية.
- كل بنود التكلفة اختيارية، والفارغ يحسب 0.
- سعر البيع إدخال يدوي.
- إجمالي التكلفة والربح يحسبان تلقائياً.
- إجماليات البيع والتكلفة والربح والمدفوع والمتبقي لجميع العاملات.
- خطة دفع كاملة أو على دفعات مع عدد الدفعات وتاريخ كل دفعة وحالتها.
- إدارة دفعات مستقلة لكل عاملة: تعديل/حذف دفعة واحدة دون تعديل باقي الحساب.
- حالة التسديد: مسدد، مدفوع جزئياً، غير مسدد، مع المتبقي.
- حقول بيانات العاملة الأساسية اختيارية.
- زر إلغاء حقيقي لا يحفظ التعديلات.
- وضع نهاري وليلي محفوظ تلقائياً.
- تحسين نموذج العاملة ولوحة الحسابات.
- اختبار Telegram داخل الإعدادات، مع فحص حالة الإعداد.
- الحفاظ على النسخ الاحتياطي والاستيراد وتسجيل الدخول والمستخدمين والصلاحيات.

## Telegram
في Cloudflare Pages أضف Secrets/Environment Variables:
- TELEGRAM_BOT_TOKEN
- TELEGRAM_CHAT_ID

ثم تأكد أن مجلد `functions` مرفوع كما هو. من الإعدادات داخل النظام اضغط «اختبار إرسال Telegram»؛ إذا فشل، ستظهر رسالة توضّح أن إعداد Cloudflare يحتاج مراجعة.

ملاحظة: هذا المشروع يستخدم localStorage كما في النسخة الأصلية، لذلك النسخة الاحتياطية مهمة عند تغيير الجهاز أو المتصفح.
