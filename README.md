# روزنا — النسخة الكاملة

هذه النسخة مبنية على المواصفات المعتمدة للنسخة التجريبية.

## الموجود
- تسجيل الدخول.
- بقاء تسجيل الدخول بعد تحديث الصفحة Refresh.
- تسجيل الخروج يدويًا.
- العاملات.
- الجنسيات: إثيوبيا، غانا، بوروندي، الفلبين، بنغلادش، نيبال، أوغندا، أخرى.
- جنسية الكفيل مستقلة عن جنسية العاملة.
- الكفلاء.
- الدفعات.
- المصاريف.
- المتابعة.
- التقارير والحسابات.
- إجمالي الدفعات والمصاريف والفرق.
- إدارة اسم المدير وبريده.
- إضافة الموظفين.
- أدوار الموظفين: موظف، حسابات، مشاهد.
- تحديد صلاحيات كل موظف.
- تعديل وحذف الموظفين.
- تغيير كلمة مرور المدير.
- تغيير اللون الرئيسي للواجهة.
- تصدير واستيراد نسخة احتياطية.
- العقود محذوفة.
- عدم المحكومية محذوفة.
- تنبيه Telegram عند تسجيل الدخول، بدون ربط برقم الهاتف.

## Telegram
لا تضع Bot Token في GitHub أو داخل app.js.

في Cloudflare أضف Secrets:
- TELEGRAM_BOT_TOKEN
- TELEGRAM_CHAT_ID

الملف functions/api/telegram-login.js يستقبل تسجيل الدخول ويرسل التنبيه إلى Telegram.

إذا كان المشروع منشورًا كـ Cloudflare Pages، ارفع مجلد functions كما هو.
